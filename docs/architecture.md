# Architecture
App/Core: design tokens and shared UI. App/Models: immutable catalog/configuration models, including appearance and interaction profile. App/Features: SwiftUI views; Discover appearance filters and the shared editor chrome. App/Services: persistence, RevenueCat/StoreKit purchase boundary, optional HTTPS content overlay, rewarded test provider, exports. App/Scene: realistic SpriteKit preview plus pixel worlds driven by InteractiveSceneBehavior; both have deterministic export rendering. Widgets: separate WidgetKit extension, App Group snapshot. App/Resources: versioned catalog, original artwork, localization. Remote content can overlay titles, visibility, order and artwork URLs; it cannot grant Pro. Gyro/touch physics are app-only.
