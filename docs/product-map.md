# Product map

Welcome offers an immediate interactive scene and a single Explore action. Discover contains the featured scene, category filters, catalog search and theme packages. Selecting a scene opens Editor; Save & set up opens Export; Save to Photos requests permission and performs the chosen export. Successful export offers the persistent installation guide.

Library contains saved configurations and favorites. Settings contains local Pro testing, restore, installation help and privacy information. Packages contain icons and widget styles. There is no account, forced first-launch ad or forced paywall.

Appearance filters keep Realistic and Pixel in the same Discover grid. Pixel scenes reuse the existing editor; tilt, drag, tap and optional score mode run only while the preview is on screen. Export still writes a still, Live Photo or 3-second video. Widgets show a snapshot. The system lock, Home and Search wallpapers never execute this physics.
